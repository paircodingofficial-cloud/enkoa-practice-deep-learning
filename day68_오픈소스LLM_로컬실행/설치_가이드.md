# Ollama 설치 가이드

이 단원은 모델을 내 장비에서 실행하는 프로그램 **Ollama**를 씁니다. Ollama는 저장소 환경과 별개인 프로그램이라 따로 설치하고, 서버가 켜져 있어야 노트북에서 연결됩니다.

수업은 **RunPod 파드(Ubuntu)** 를 기준으로 합니다. 내 컴퓨터에서 실습할 때는 macOS·Windows 절을 따릅니다. 설치 방법만 운영체제마다 다르고, 확인 방법은 같습니다.

## 1. 설치하기

### RunPod 파드(Ubuntu)

파드 터미널에서 실행합니다. 볼륨 없이 만든 파드는 정지하면 초기화되므로, **파드를 새로 만들거나 다시 켤 때마다** 실행합니다.

```bash
# 설치 파일을 푸는 도구 zstd를 먼저 설치하고 공식 설치 스크립트를 실행합니다
apt-get update && apt-get install -y zstd
curl -fsSL https://ollama.com/install.sh | sh
```

- 설치 중 `WARNING: systemd is not running`과 `WARNING: Unable to detect NVIDIA/AMD GPU`가 나와도 진행합니다. 파드에는 서비스를 켜 주는 관리자(systemd)가 없어 생기는 경고이고, 서버는 2절에서 직접 켭니다. GPU는 실행할 때 잡힙니다(3절에서 확인).

### macOS

터미널에서 실행합니다. 관리자 암호를 물으면 입력합니다.

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

- `/Applications`에 Ollama 앱을 설치하고 바로 실행합니다. 메뉴 막대에 라마 아이콘이 보이면 서버가 켜진 것입니다.
- 명령 대신 <https://ollama.com/download/mac>에서 `Ollama.dmg`를 받아 응용 프로그램 폴더로 옮겨도 됩니다.

### Windows

PowerShell에서 실행합니다.

```powershell
irm https://ollama.com/install.ps1 | iex
```

- 설치 프로그램(`OllamaSetup.exe`)을 내려받아 설치하고 Ollama를 실행합니다. 작업 표시줄 오른쪽 알림 영역에 라마 아이콘이 보이면 서버가 켜진 것입니다.
- 명령 대신 <https://ollama.com/download/windows>에서 `OllamaSetup.exe`를 받아 실행해도 됩니다.
- 설치 전에 열어 둔 터미널(VS Code 터미널 포함)에서는 `ollama` 명령을 찾지 못할 수 있습니다. 터미널을 새로 엽니다.

## 2. 서버 켜기

**RunPod 파드:** 서버를 직접 켭니다. 파드를 새로 만들었을 때와 서버가 꺼졌을 때 실행합니다.

```bash
# nohup: 이 터미널 창을 닫아도 서버가 꺼지지 않게 합니다
nohup ollama serve > /workspace/ollama.log 2>&1 &
```

**macOS·Windows:** 설치하면 서버가 함께 켜집니다. 컴퓨터를 다시 켠 뒤 서버가 꺼져 있으면 Ollama 앱을 실행합니다(macOS는 응용 프로그램 폴더, Windows는 시작 메뉴).

## 3. 확인하기 (모든 운영체제 공통)

```bash
# 버전: 이 단원의 qwen3.5 태그는 0.30.0 이상에서 실행됩니다. 설치 스크립트는 최신판을 받습니다
ollama --version

# 서버 연결: 표 머리(NAME ID SIZE MODIFIED)가 나오면 켜진 것입니다
ollama list
```

- 모델 파일은 교안과 과제의 첫 코드 셀이 내려받으므로 여기서 따로 받지 않습니다.
- 노트북에서 모델을 실행한 뒤 `ollama ps`의 `PROCESSOR` 열이 `100% GPU`이면 GPU로 실행되고 있습니다. RunPod 파드와 NVIDIA GPU가 있는 Windows는 NVIDIA GPU를, Apple Silicon 맥은 맥의 GPU를 씁니다. `CPU`가 섞여 보이면 GPU 메모리가 모자라거나 GPU가 없는 것입니다.

## 4. 막혔을 때

- **노트북에서 `Failed to connect to Ollama`:** 서버가 꺼진 것입니다. RunPod 파드는 2절의 `nohup ollama serve ...` 줄을 다시 실행하고, macOS·Windows는 Ollama 앱을 실행합니다.
- **RunPod에서 `ollama: command not found`:** 새로 만든 파드라 아직 설치하지 않은 것입니다. 1절부터 다시 실행합니다.
- **RunPod에서 서버가 켜지지 않을 때:** `cat /workspace/ollama.log`로 오류를 확인합니다. `address already in use`이면 이미 켜져 있는 것이므로 그대로 진행합니다.
